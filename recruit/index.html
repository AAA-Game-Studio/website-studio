Careers

Join AAA Game Studio.

We are a small mobile game team in Hanoi. These are the roles we are looking for.

Unity Developer

  • Build and develop mobile game projects on Unity for Android and iOS
  • Come up with ideas and solutions for new game features together with the team
  • Fix bugs and improve game features and performance
  • Integrate third-party SDKs into the game
  • Work with team members to operate and optimize the product

Game Designer

  • Analyze the company's products and conceive game environments, characters and in-game elements, control mechanics…
  • Change the design of existing game content; update and improve current content to raise and extend the standard.
  • Clean game data, fix design-related bugs, write scripts and design game content
  • Use the design toolset; playtest and verify current games together with the team

2D Game Artist

  • Take part in designing characters, items and environments for casual games
  • Work and collaborate with related departments to develop ideas
  • Proficient in graphics software such as Photoshop and 2D art (hand drawing, digital coloring, design and illustration)
  • Experience in UI, UX or Spine animation is an advantage
  • Understand and be passionate about game design, with creativity in developing game concepts
